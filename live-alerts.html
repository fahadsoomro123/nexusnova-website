How a local threshold works

Choose one metric, decide whether you care about a value moving above or below a threshold, and save it. For example, if you are watching USD/PKR and only want the page to flag values above a chosen reference, select USD/PKR, choose “Above” and enter that threshold. The page compares the saved threshold with the applicable cached NexusNova dataset while the page is open.

This is not a background notification service

The threshold is stored on this browser and survives ordinary page reloads or browser restarts, but checking is not a server-side subscription. NexusNova checks its local cached datasets every 60 seconds only while this page is open, so closing the tab stops active checking. Browser notifications also depend on permission and the page being able to perform its check; they do not turn this feature into a 24/7 server monitor.

Understand the data before setting a threshold

Gold is the international-derived PKR reference shown by NexusNova, not a local Sarafa quote. Fuel values use the published Pakistan PSO reference. Currency uses the daily reference dataset. Each underlying LIVE page shows source or reference context where available, so use the metric-specific page when you need to understand what a number represents.

Thresholds are signals, not trading or purchasing instructions

A triggered threshold only means the referenced value crossed the number you saved according to the latest cached dataset available to the page. It does not predict future prices, confirm a dealer quote, execute a transaction or provide financial advice. Market and official price references can update on different schedules.

Privacy and reset behavior

Your selected metric, direction and threshold are stored in localStorage on this browser. NexusNova does not need an alert account, phone number or email address for this feature. Clearing site storage, changing browser profiles or using another device can remove or separate the saved setting. Use the Clear alert button when you no longer want the threshold retained on this browser.
