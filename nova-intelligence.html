ARCHITECTURE

Understand. Decide. Act. Respond.

Nova-specific UI stays separate from Hub and Travel. The backend remains the secure orchestration boundary.

01Understand

Interpret natural language, informal phrasing, mixed language and typos.

02Decide

Choose answer, tool, live search, multiple steps, clarification or limitation.

03Act + verify

Execute only allowlisted capabilities and treat returned data as evidence.

04Respond

Render the result with the structure and recovery path the user actually needs.

NO FAKE INTELLIGENCE

Truthful by construction.

No fabricated prices, citations, availability, provider responses or completed actions.

BOUNDED + PRIVATE

Built to stay controlled.

Browser context, request size, output size and provider work remain bounded to reduce abuse and runaway cost.

What happens when an integration is unavailable?

Nova can retry when appropriate, route to a working native capability, ask for missing information, or explain the limitation without pretending success.

Does Nova need every request to go to AI?

No. A dedicated deterministic NexusNOVA tool is preferred when it can solve the task directly.
