HOW NOVA WORKS

One assistant layer, multiple safe ways forward.

Nova keeps intent understanding, provider calls, capability selection, execution and response formatting separate. That lets the system grow without turning the interface into a giant command list.

01Understand

Interpret arbitrary natural language, including informal phrasing, Roman Urdu, mixed language and typos.

02Decide

Choose between a direct answer, a real NexusNova capability, web search, multiple steps, clarification or an honest limitation.

03Act + verify

Execute only allowlisted tools and treat returned data as evidence rather than instructions.

04Respond

Give the user an answer, result, source-backed synthesis, clarification or useful recovery path—never a raw technical failure.

NO FAKE INTELLIGENCE

Truthful by construction.

Nova never claims a live search, provider response, price, travel result, citation or completed action unless the connected system actually supplied it.

BOUNDED + PRIVATE

Useful without hoarding context.

Conversation context is bounded in the browser session. Requests, retries, tool calls and output size are capped to reduce abuse and runaway cost.

What can Nova handle?

General questions, explanations, writing and rewriting, translation, calculations, troubleshooting, tool discovery, current-information requests, planning, comparisons and follow-up questions can all enter through the same natural-language interface. The actual answer depends on the configured provider and connected capabilities.

What happens when an integration is unavailable?

Nova does not fabricate the missing result. It can retry or switch provider when configured, use a native NexusNova capability, ask for a missing detail, or explain the limitation with a useful next step.
