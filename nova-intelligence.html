HOW IT WORKS

A straightforward workflow

Nova is an interface to existing connected capabilities, not a promise that every provider or external service is always available.

01Describe

State your goal and relevant constraints without sharing secrets.

02Route

Nova checks the request against its supported capabilities.

03Check

Missing inputs or unavailable providers are called out when encountered.

04Continue

Use a connected tool or refine the request based on the response.

Privacy reminder

This workspace uses the existing NexusNova service endpoint. Do not submit passwords, private records, payment details or API keys.

Source reminder

Do not treat an answer as live or authoritative unless it identifies a current source and the provider returned usable data.
