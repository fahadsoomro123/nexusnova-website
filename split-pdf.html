Split PDF

Extract selected pages from a PDF and save them as a separate document.

Page syntax

Use commas and ranges, for example 1-3,5 to keep pages 1, 2, 3 and 5.

Useful for

Removing unneeded pages, sharing a chapter or isolating pages for a form submission.

Before splitting a PDF

Check the original document's page order first, then use comma-separated page numbers and ranges to select only the pages you need. Large files can require more device memory during browser processing.

Splitting a PDF while keeping pages organized

Use PDF splitting when you need only selected pages from a larger document or want to separate one file into smaller parts. Before starting, note the page numbers you need and remember that printed page labels can differ from the PDF viewer’s numeric page positions.

After exporting, open every new file and confirm the first and last page, page order and readability. Keep the original PDF until you are sure nothing was omitted. If the document contains confidential material, use an appropriate device and sharing method for that level of sensitivity.

Practical checks

  • Write down the required page range before splitting.
  • Verify each exported file rather than trusting the filename alone.
  • Keep the source PDF until the new files have been checked and backed up.

Quick FAQ

Why can page numbers in the document differ from the PDF page count? A document may include covers, front matter or custom printed numbering, while a PDF viewer counts every page in file order.

Check page numbers, forms and signatures after extracting PDF pages

PDF viewers count file pages in order, but printed page labels inside a document can start later or use Roman numerals. Before entering a range, compare the pages you need with the viewer’s page positions so a cover or front-matter page is not accidentally omitted.

Worked example / practical use: For a 10-page PDF, a selection such as 1-3,5 means file pages 1, 2, 3 and 5. Open the exported PDF and verify the first page, last page and total page count before sending it to someone else.

Interactive forms, bookmarks, links, attachments, digital signatures and other advanced PDF features can behave differently when pages are extracted into a new document. If those features matter, inspect them explicitly and retain the original PDF until the new file has been checked.

Before you rely on the result

  • Match requested pages to the viewer’s numeric page positions.
  • Verify order and page count in the exported file.
  • Check forms, links or signatures when the source PDF uses them.

Split PDF: clear guide for real use

Split PDF extracts selected pages or ranges from a larger PDF into a new document. It is useful when only part of a report, statement or scanned file needs to be shared.

How to use Split PDF

  1. Keep the original PDF or source files, then add only the documents or pages needed for the job in Split PDF.
  2. Use Split PDF to create the new PDF and immediately reopen the result to check order, page count, orientation and readability.
  3. Retain the source files until the output from Split PDF has been checked for forms, links, signatures or other document features that matter.

Practical example

For a 10-page file, selecting pages 1-3 and 5 should create an output containing file pages 1, 2, 3 and 5. Open the result and verify the first page, last page and page count before sending it.

Limits, privacy and checks

Printed page labels inside a document can differ from the viewer’s numeric page positions, and forms, bookmarks, links or digital signatures may behave differently after extraction. Keep the original PDF until the new file and any advanced features are checked.
