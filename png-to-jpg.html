Use JPG when the destination needs an opaque image

PNG is lossless and can store alpha transparency; JPEG is lossy and is commonly accepted by photo upload forms. This converter creates a JPEG by flattening the image onto white first. Transparent PNG pixels therefore become white in the output, so it is not suitable when a logo, icon or product cutout must stay transparent. Keep PNG for transparency, or first place the image over a deliberate background in an editor if the final JPG should have a colored backdrop.

What happens to quality and dimensions?

The browser-canvas conversion keeps the original pixel dimensions and encodes a new JPEG with a fixed quality setting. JPEG discards image data, so thin text, sharp interface edges and smooth gradients can look softer or show compression artifacts after export. Converting a PNG to JPG does not improve the original image or sharpen it. Keep the source PNG until you have opened the downloaded JPG and checked the edges, colors and overall appearance.

Check the size limit as a separate requirement

A JPEG photo may be smaller than a PNG, but the exact size depends on the image. This tool does not resize pixel dimensions. If a site has a megabyte limit, check the exported file size and use a resizer or compressor only if needed; changing format repeatedly is not a substitute for choosing appropriate dimensions and can introduce more JPEG loss. A browser canvas export should not be assumed to retain metadata such as EXIF camera, date or location details.

See MDN's image format guide for the JPEG/PNG trade-offs. If transparency must remain, use JPG to PNG only for the reverse format task, or keep the original PNG; if the destination requires different dimensions, use the Image Resizer.

Use JPG when the destination needs a compact, opaque image

PNG and JPG solve different problems. PNG is generally useful for sharp graphics, screenshots and transparent artwork; JPG is a widely supported lossy format for photographs and uploads that require an image without transparency. Converting PNG to JPG can improve compatibility with forms or older software, but it may also increase or decrease file size depending on the image, quality setting and dimensions.

Prepare and verify the converted image

  1. Keep the original PNG if it contains transparency or details you may need later.
  2. Choose the image and any available output-quality setting.
  3. Run the conversion and download the newly encoded JPG.
  4. Open the result at normal size and zoom in on text, thin lines and edges to check compression artefacts.
  5. Confirm that the background looks correct anywhere the original was transparent.

For example, a logo designed with a transparent background may look fine on a white page after conversion but show a white rectangle when placed over a dark banner. If transparency is required, keep PNG or use another format that supports alpha. A repeated JPG export can also introduce more compression damage, so convert from the cleanest available source rather than repeatedly resaving copies.

What conversion does not do

Changing the file format does not recreate missing detail, upscale the image automatically or prove that the output meets a website's upload-size limit. Resolution, compression quality, dimensions and format are separate constraints. If the destination specifies a maximum pixel size or a file-size threshold, check that requirement after conversion.

PNG-to-JPG questions

Will the JPG remain transparent?

No. JPG does not support an alpha channel; transparent areas need a background colour in the exported image.

Will JPG always be smaller?

No. File size depends on image content, dimensions and encoding settings. Compare the actual exported file.
