Time Duration Calculator

Find the time between two clock times, including overnight ranges.

Ready.

How the duration is calculated

Each clock time is converted to minutes after midnight. The calculator subtracts the start value from the end value, then displays the difference as hours, minutes and total minutes. For a same-day example, 09:00 to 17:00 is 8 hours.

Overnight durations

If the end time belongs to the next day, enable the next-day option. For example, a start time of 22:30 and an end time of 01:15 should be treated as an overnight range, so the calculator adds 24 hours to the end before subtracting. This produces 2 hours 45 minutes instead of a negative duration.

More worked examples

From 08:45 to 12:10, the elapsed time is 3 hours 25 minutes, or 205 total minutes. From 23:50 to 00:20 on the next day, the elapsed time is 30 minutes. These examples show why the next-day setting matters whenever the end clock time is earlier than the start clock time.

Useful for schedules, not payroll rules

The tool is useful for checking meeting length, study sessions, shifts, travel segments or any simple clock-time interval. It does not automatically subtract lunch or rest breaks. If a work shift runs from 09:00 to 17:00 with a 30-minute unpaid break, the raw duration is 8 hours but the paid duration would need a separate 30-minute adjustment.

This tool compares clock times rather than full calendar dates. It does not apply overtime rules, payroll rounding, daylight-saving transitions or timezone changes automatically. For travel or international meetings, use a timezone-aware tool instead. For spans involving specific dates, use the Date Difference Calculator.

Edge cases to check

If start and end are the same time, the result is zero unless you explicitly mean a full 24-hour overnight period; this calculator does not infer that intention. Also confirm whether your schedule crosses midnight before using the result in a report or invoice.

When a clock-time calculation is useful

This calculator fits simple intervals such as meetings, study sessions, travel segments or shifts. It uses ordinary time-of-day values and can explicitly treat the end time as belonging to the following day.

The overnight option matters when the end clock is numerically smaller than the start. A 22:30 to 01:15 schedule represents an overnight interval when the next-day condition applies, rather than a negative duration.

Know the limits

Raw elapsed time is not the same as paid time or timezone-aware duration. Breaks, overtime rules, daylight-saving changes and date-specific rules require additional context, so apply those rules separately when they matter.

Apply the duration result to the real schedule

This calculator is useful for comparing elapsed clock time, but real schedules often contain rules that the arithmetic alone cannot know. A work shift may have unpaid breaks, a booking may cross midnight, and a meeting may involve participants in different timezones. Treat the displayed duration as the transparent time interval between the selected endpoints.

For repeated schedules, record whether the end point is on the same day or the following day. That single assumption prevents a common error where an overnight interval is interpreted as a negative number. When an interval crosses a timezone or daylight-saving transition, use a timezone-aware date calculation rather than relying on a fixed offset.

Keep schedule rules separate

If the duration is being used for payroll, billing or compliance, apply the applicable official rules separately after calculating the raw elapsed time. The calculator can make the arithmetic reproducible; it cannot determine which breaks, exclusions or legal rules apply to a real situation.

Time-duration questions

How should I handle breaks?

This calculator measures the time range you enter. If you need paid work time, study time or billable duration after subtracting breaks, apply the relevant break rules separately and keep a record of the assumptions.

Why should I check the start and end date?

Overnight ranges can cross midnight, and longer intervals can cross a date change or daylight-saving transition. Confirm the date context rather than comparing clock digits alone.

For travel, shifts or deadlines, use the result as an arithmetic check and verify the schedule in the authoritative calendar or timekeeping system. A duration calculator cannot determine an employer's payroll policy, whether a break is paid or which legal rule applies to a particular shift.
