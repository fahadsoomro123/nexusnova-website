What CIDR means

The number after the slash is the network prefix length. A /24 leaves 8 host bits, giving 256 total addresses. Traditional IPv4 subnets from /0 through /30 reserve the network and broadcast addresses; /31 and /32 are special cases where this calculator reports all addresses as usable endpoints.

Privacy for network inputs

This is a mathematical subnet calculator, not an IP-location lookup. The entered address stays in your browser and no network request is needed.

CIDR results describe address ranges, not network reachability

A CIDR calculation can identify the network range, mask and address boundaries for the entered prefix. It does not prove that a host exists, accepts traffic or is reachable through firewalls, routing rules, NAT or provider filtering.

Use the result when planning or checking IPv4 ranges, then verify the actual network configuration separately. Avoid assuming that every numerically valid address in a range is assignable in every environment.

Read a CIDR result in network context

The prefix length determines how many IPv4 bits belong to the network portion and how many remain for hosts. A /24 leaves eight host bits, while a /16 leaves sixteen. The calculated network and broadcast boundaries are mathematical properties of that block.

Cloud platforms, routers, VPNs and firewalls can impose additional rules. Some environments reserve addresses for infrastructure, and security policies can make an otherwise valid address unusable for a particular service.

Cross-check before a live network change

Verify the prefix, compare the calculated range with the current configuration, and confirm provider-specific reservations. CIDR arithmetic can identify a range; it cannot prove a host exists or accepts traffic.
