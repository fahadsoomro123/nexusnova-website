What CIDR means

The number after the slash is the network prefix length. A /24 leaves 8 host bits, giving 256 total addresses. Traditional IPv4 subnets from /0 through /30 reserve the network and broadcast addresses; /31 and /32 are special cases where this calculator reports all addresses as usable endpoints. The tool accepts IPv4 prefixes from /0 to /32; it does not calculate IPv6 networks.

Worked examples: /24, /26, /31 and /32

For 192.168.1.10/24, the network is 192.168.1.0 and the broadcast address is 192.168.1.255. There are 256 addresses; the conventional host range is 192.168.1.1–192.168.1.254, or 254 hosts.

For 192.168.1.70/26, the first 26 bits identify the network: 192.168.1.64 through 192.168.1.127. That block contains 64 addresses, with the conventional usable range 192.168.1.65–192.168.1.126, or 62 hosts. A /26 is one quarter of a /24 address block.

Read a CIDR result in network context

The prefix length determines how many IPv4 bits belong to the network portion and how many remain for hosts. A /24 leaves eight host bits, while a /16 leaves sixteen. The calculated network and broadcast boundaries are mathematical properties of that block.

Use the subnet result for planning, not reachability
