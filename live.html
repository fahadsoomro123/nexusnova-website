How NexusNova LIVE handles freshness

“Live” is the name of the hub, not a promise that every dataset updates every second. Currency reference rates are daily data. Gold is an international XAU/USD reference converted using the published USD/PKR reference and is not presented as a local Sarafa quote. Fuel values carry each official source's publication or effective date. Weather values are MET Norway model forecasts; worldwide manual search is user-triggered, satellite imagery is global, and radar coverage is explicitly regional. Sports uses SportScore's live/recent match feed and only labels upstream live/in-progress statuses as LIVE. AQI values, when source access and coverage validate, are rolling PM2.5-based estimates from OpenAQ observations. Crypto uses scheduled Coinranking snapshots with source-provided 24-hour change. Earthquakes use a cached USGS M2.5+ past-day feed.

Why cached data files are used

The Pakistan Today dashboard and dedicated LIVE pages read NexusNova's already-published local datasets wherever practical. Manual worldwide weather search and sports requests are user-triggered or modestly refreshed in-browser rather than bulk-harvested in the background.

Important limitation

Reference market data can differ from executable prices, sports results can be corrected by their source, weather forecasts can differ from observations, radar networks have regional coverage, air quality can vary within a city, and earthquake parameters can be revised after further analysis. Always use the named source and relevant official authorities for high-stakes decisions.
