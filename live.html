How NexusNova LIVE handles freshness

“Live” is the name of the hub, not a promise that every dataset updates every second. Currency reference rates in this first release are daily data. Future fuel feeds may be daily, fortnightly or weekly depending on the official publisher, while sports can be faster only when the selected source genuinely provides that status.

Why a cached data file is used

NexusNova refreshes this currency dataset on the server-side publishing workflow instead of making every visitor call an upstream API. That keeps the public page lightweight, avoids exposing API credentials, reduces unnecessary third-party requests and makes the displayed source date easy to audit.

Important limitation

Reference exchange rates are useful for estimates and comparisons. The amount offered by a bank, exchange company, card network or remittance provider can differ because of spreads, fees, timing and local market conditions.
