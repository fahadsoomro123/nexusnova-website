How NexusNova gets the crypto values

A scheduled server-side publisher requests the five featured assets from Coinranking by their exact Coinranking UUIDs. It validates each symbol, price and 24-hour percentage change before writing a public cached JSON file. Visitors read that local cache instead of calling the upstream API, so the API key remains private and visitor traffic does not multiply source requests.

How the PKR reference is calculated

Coinranking remains the source for the USD crypto price. If NexusNova's cached daily USD/PKR reference is available, the displayed PKR amount is calculated as USD crypto price × daily USD/PKR reference. It is not a Pakistan crypto exchange, OTC, card, bank or cash execution price.

Freshness and market limitations

Crypto markets can move materially between scheduled snapshots. Exchange prices can also differ because of liquidity, venue, spreads and fees. “NexusNova LIVE” is the hub name and does not mean every crypto value updates every second.
