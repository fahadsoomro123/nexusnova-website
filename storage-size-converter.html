Decimal vs binary storage units

Storage labels are not always interpreted with the same scale. Drive and device manufacturers commonly use powers of 1000, so one decimal GB equals 1,000 MB and one decimal MB equals 1,000 KB. Many operating systems and technical contexts have historically used powers of 1024, where each step is 1024 times the previous unit.

Worked examples

With decimal scaling, 1 GB equals 1,000 MB and 500 MB equals 0.5 GB. With base-1024 scaling, 1 GB equals 1,024 MB and 512 MB equals 0.5 GB. The numerical difference becomes more noticeable at larger capacities, which is why a drive advertised with decimal units can appear smaller when software reports a binary-style value.

Why the displayed capacity can look smaller

A storage device advertised with decimal units can appear to have a smaller numerical capacity when software reports a binary-style value. The underlying byte count has not necessarily changed; the difference can come from the unit convention used to label that byte count. Choose the scale that matches the source you are comparing.

Which mode should you choose?

Use decimal mode when comparing manufacturer specifications, internet transfer quotas or services that explicitly define KB/MB/GB in powers of 1000. Use binary mode when the software or documentation you are comparing uses powers of 1024. If a specification uses IEC names such as KiB, MiB or GiB, those are explicitly binary units even though this simple converter labels the selector KB/MB/GB for broad familiarity.

Limits of the conversion

This converter uses the selected base consistently from bytes through TB. It does not estimate free space, filesystem overhead, reserved partitions, compression, deduplication or cloud-provider billing rules. Two files with the same byte size can also occupy different amounts of physical storage depending on filesystem allocation.

Decimal GB and binary GiB are different conventions

Storage labels and operating-system displays may use different unit systems. In decimal units, 1 KB is 1,000 bytes, 1 MB is 1,000,000 bytes and 1 GB is 1,000,000,000 bytes. In binary units, 1 KiB is 1,024 bytes, 1 MiB is 1,024 KiB and 1 GiB is 1,024 MiB. Older interfaces sometimes use KB, MB or GB while actually counting in binary multiples, which is one reason the same device can appear to have different capacities in different places.

Choose the conversion mode for the question

Use decimal units when reading most manufacturer storage-capacity labels or comparing file sizes that explicitly use powers of 1,000. Use binary units when the specification or tool names KiB, MiB or GiB, or when you need a calculation based on powers of 1,024. The labels matter more than the number of decimal places.

Check a result before using it

  1. Confirm whether the original value is bytes, decimal KB/MB/GB or binary KiB/MiB/GiB.
  2. Select the same convention for the destination conversion.
  3. Compare the numeric value and its unit abbreviation, not just the number.
  4. When planning a download or upload, leave room for file-system overhead, additional files and temporary working space.

As an example, converting a decimal 1 GB to binary GiB produces a value below 1 GiB because the binary unit contains more bytes. That is a unit-definition difference, not evidence that the conversion lost data. Real available disk space can be lower still because formatted capacity and reserved system space are separate factors.

Storage conversion questions

Does converting a file size change the file?

No. This tool converts the way the size is expressed; it does not compress, expand or modify a file.

Why does a 1 TB drive show less than 1 TiB?

A decimal terabyte contains 1,000,000,000,000 bytes, while a tebibyte uses powers of 1,024. Device formatting and reserved space affect the final amount available to store files.
