DAILY TOOL // RANDOM

Random Name & Item Picker

Draw one or up to 100 winners from a list using secure randomness in your browser, with optional duplicate removal and copyable results.

Blank lines are ignored. Entries are processed on this device; the list is not uploaded by this picker.

Enter at least one item to begin.

How this draw works

Enter one name or item on each line and choose how many winners to draw. The picker uses the browser's crypto.getRandomValues() source and rejection sampling to select an index without the small modulo bias created by a simple remainder operation. The input list stays in this browser tab and is not submitted to a NexusNova server.

Draw several winners without repeating an entry

After each selection, that entry position is removed from the draw pool. A single draw therefore cannot select the same list position twice. The winner order is the draw order, and the result can be copied as plain text for your own notes.

Example: with “Ali”, “Sara” and “Hamza” and a winner count of 2, the tool draws two distinct list positions. If you leave “Ali” on two separate lines, those are still two eligible positions unless you enable duplicate removal.

Choose how duplicate entries are handled

By default, each non-empty line is a separate entry. Repeating a line gives that text multiple chances in the draw. Turn on Remove duplicate entries to keep only the first copy of each exact line before drawing. Matching is case-sensitive, so “Ali” and “ali” are treated as different entries.

Clean list trims surrounding spaces and removes blank lines without changing duplicate entries. Shuffle entries randomizes the visible order with the same browser randomness before you draw.

Use it for everyday decisions, not audited raffles

This tool is useful for classroom participation, picking a game, assigning informal turn order or choosing among ordinary options. Agree on the final list and duplicate rules before running the draw so everyone knows what is eligible.

Although the selection uses the browser's cryptographic randomness, NexusNova does not provide a certified public draw, identity verification, timestamped audit trail or independently verifiable raffle record. Do not rely on this page for regulated giveaways, gambling, legal selections or any process that requires formal fairness evidence.

Define entries and duplicate rules before drawing

A list picker chooses from the entries you provide. If a name appears twice, it may represent two separate tickets or it may be an accidental duplicate; those are different rules. Decide whether repeated entries count as extra chances before generating results. Changing the list after seeing a draw can undermine confidence even when the selection mechanism itself works as intended.

A transparent workflow for a small draw

  1. Prepare the complete list and check spelling or missing entries.
  2. Choose whether exact duplicates should remain or be removed.
  3. Set the number of winners and review the on-screen rules before starting.
  4. Save or copy the outcome if the participants need a record.
  5. Explain that the draw is an informal browser selection unless a formal audited process was used.

For example, if a club asks each member to enter once, duplicates should usually be removed or resolved before the draw. If official rules allow multiple tickets per person, repeated entries may be intentional. The tool cannot determine which policy is fair for your event; it can only apply the list and options you supply.

Privacy and fairness limits

Do not include sensitive personal information in a public or shared list unless you have permission and a genuine need. A browser picker is useful for casual choices, classroom activities or informal team decisions, but it does not provide an independent audit trail, prove that the list was complete or meet every regulated lottery requirement. For prizes or decisions with legal or financial consequences, define the rules in advance and use a method suitable to the event.

Random-picker questions

Can one person win more than once?

That depends on whether you select multiple winners with replacement or remove selected entries after each draw. Review the tool's duplicate and repeat options before starting.

Does the result prove a public competition was fair?

No. A fair process also depends on eligibility, the published list, rules, oversight and how the result is recorded.
