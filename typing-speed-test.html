How WPM is calculated

This test uses the common convention of five typed characters as one word. Gross WPM is calculated from the number of characters you entered divided by five and adjusted to one minute.

How accuracy is calculated

Each typed character is compared with the character at the same position in the sample. Accuracy is the share of typed characters that match. This makes the result easy to reproduce, but different typing websites may use slightly different scoring rules.

How to improve typing speed

  • Prioritize accuracy before pushing speed.
  • Keep your hands relaxed and use consistent finger placement.
  • Practice short sessions regularly instead of one long session.
  • Repeat tests with unfamiliar text, not only memorized passages.

FAQ

What is a good typing speed?

There is no single target for every job or learner. Compare your own results over time and aim for a balance of speed and accuracy.

Does NexusNova save my typed text?

No. The test runs in browser JavaScript and this page does not send the text you type to NexusNova.
