How the estimate works

The weight-only calculation is straightforward: parameter count × bits per parameter ÷ 8. NexusNova converts that byte estimate to GiB and then adds your chosen runtime headroom.

7B at FP16

Seven billion parameters at 16 bits require roughly 13 GiB for weights before runtime overhead.

7B at 4-bit

The same model at 4-bit uses roughly one quarter of the weight memory, before quantization metadata and runtime overhead.

Training needs more

Training often needs substantially more VRAM for gradients, optimizer states and activations. This calculator is mainly a quick inference/loading estimate.

FAQ

Is this an exact VRAM requirement?

No. It gives a transparent weight-memory estimate plus headroom. Real usage can be higher or lower depending on the model implementation and workload.

VRAM estimates are planning numbers, not hardware guarantees

Model weights are only one part of memory use. Precision, quantization, context length, KV cache, batch size, runtime buffers and the inference framework can all change the real requirement. Two setups using the same model can therefore consume different amounts of VRAM.

Leave headroom for the runtime

If an estimate lands very close to your GPU capacity, treat it as a warning rather than a promise that the model will fit. Practical deployments usually need headroom for the framework and temporary allocations. Lower precision, a shorter context or partial CPU offload may reduce GPU memory pressure, but each option can change speed or output behavior.
