How local browser storage works

When you press Save, the note is stored with the browser's local storage feature on the current browser profile. The page reads that saved value the next time you open the tool from the same browser and device. NexusNova does not intentionally send the note to a separate application server.

Privacy and backup limits

Local storage is convenient, but it is not a permanent backup. Clearing site data, using private browsing, resetting the browser, changing devices or uninstalling the browser can remove the note. Do not use this page as the only copy of important records, and do not treat it as a password manager or secure vault for passwords, recovery phrases, payment details or private keys.
