Why these tools are separated

A browser can calculate CIDR locally, but it cannot directly inspect the TLS certificate bytes of an arbitrary remote site. NexusNova therefore uses the narrowest appropriate method for each task and identifies third-party public APIs where one is needed.

Privacy and limitations

Public-IP and certificate lookups run only when you request them. Third-party services involved in a lookup receive the network request as they would for any direct web call. High-stakes security decisions should still be verified with your hosting provider, certificate authority or local command-line tooling.
