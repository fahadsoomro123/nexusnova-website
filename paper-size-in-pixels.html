A4 size in pixels at 150 DPI and 300 DPI

A4 paper measures 210 × 297 mm. At 150 DPI, that converts to approximately 1240 × 1754 pixels. At 300 DPI, it is approximately 2480 × 3508 pixels. These values are commonly used when preparing printable images, scanned pages and image-based PDF documents.

Why DPI changes the pixel dimensions

Paper has a physical size, while pixels describe a digital image. DPI connects the two. If the physical paper size stays the same and DPI doubles from 150 to 300, the pixel count along each edge also roughly doubles. That is why an A4 image prepared at 300 DPI contains far more pixels than an A4 image prepared at 72 or 96 DPI.

What does 1240 × 1754 mean?

A file that is 1240 × 1754 pixels closely matches portrait A4 at 150 DPI. The same pixel dimensions do not define a paper size by themselves, though: the intended DPI is also required. Enter the pixel width, height and DPI in the reverse calculator above when you need to compare a file with standard A-series paper sizes.

A0, A2 and other A-series sizes in pixels

The ISO A-series keeps the same aspect ratio as sizes get larger or smaller. A0 is the largest size in this calculator, followed by A1, A2, A3, A4, A5 and A6. Because pixel dimensions depend on DPI, there is no single universal pixel size for A0 or A2. Choose the DPI that matches your print or design workflow and the calculator will return the corresponding dimensions.

Which DPI should I use?

  • 72 or 96 DPI: useful mainly for screen-oriented layouts or rough previews where physical print detail is not the priority.
  • 150 DPI: a moderate-resolution option that reduces image size while retaining reasonable print detail for many everyday uses.
  • 300 DPI: a common target for higher-quality printing and a useful default when a print provider specifically requests 300 DPI.
  • 600 DPI: creates very large pixel dimensions and is usually only needed for workflows that explicitly require high-resolution line art, archival scans or specialized printing.

Always follow the printer, publisher or service specification when one is provided; a higher DPI is not automatically better if it only creates an unnecessarily large file.

Preparing A4 images for PDF

If you are preparing images for a document, first choose the output paper size and DPI, then resize the image without distorting its aspect ratio. The Image Resizer can help adjust pixel dimensions, while the Image Compressor can reduce file size. When the images are ready, the JPG to PDF Converter can place JPEG images on A4 PDF pages in your browser.

Rounding and print bleed

Pixel calculations often produce fractions, so this tool rounds to the nearest whole pixel. Professional print jobs can also require bleed beyond the final trimmed paper size. If a printer specifies bleed, crop marks or a particular template, use those specifications instead of treating the ISO paper dimensions alone as the complete print setup.
