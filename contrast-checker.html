What the ratio means

The contrast ratio is calculated from the relative luminance of the foreground and background colors. A higher ratio means a stronger luminance difference. This tool reports the numeric ratio and compares it with common WCAG 2.2 text thresholds rather than judging the design as a whole.

WCAG 2.2 thresholds used here

For normal text, WCAG 2.2 Success Criterion 1.4.3 specifies at least 4.5:1 for Level AA and 7:1 for Level AAA. Large-scale text has a lower minimum of 3:1 for AA and 4.5:1 for AAA. These checks apply to text contrast; non-text interface components have different requirements.

How to use the result

Check the actual text size, weight and visual context before making a design decision. A passing ratio does not prove that an entire page conforms to WCAG because accessibility also covers focus indicators, keyboard access, semantics, resizing, motion, forms and many other requirements.

Contrast checker FAQ

Does a passing color ratio mean my page is WCAG conformant?

No. This tool checks color contrast only. WCAG conformance involves many additional success criteria, and different content can have different requirements.

What counts as large text for the WCAG check?

WCAG defines large-scale text by font size and weight rather than by a single universal CSS pixel value. Use the current WCAG understanding guidance when making a formal accessibility assessment; this page only compares the ratio against the large-text thresholds.

Does this tool send my colors to a server?

No. The calculation runs locally in the browser. Only the hexadecimal color values you enter are used by the page to calculate the ratio and preview the sample.

Reference: W3C Web Content Accessibility Guidelines (WCAG) 2.2.
