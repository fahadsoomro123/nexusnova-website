Scientific Calculator

Calculate common scientific functions including sine, cosine, tangent, square roots, logarithms, powers and percentages.

Angle mode

Trigonometric inputs are interpreted in degrees in this calculator.

When to use it

Useful for homework checks, quick engineering estimates and everyday mathematical work. Verify important technical calculations independently.

Scientific calculation basics

This calculator performs one selected operation at a time using Value X and, where needed, Value Y. Square root uses X, base-10 logarithm uses X, natural logarithm uses X, power calculates X raised to Y, and percentage calculates X% of Y.

Worked examples for the operations in this calculator

For trigonometry, enter the angle in degrees as X. With X = 30, sin(X°) is approximately 0.5. With X = 60, cos(X°) is approximately 0.5. The calculator converts the degree input to radians internally before using the browser's trigonometric functions.

For roots and logarithms, X = 144 gives √X = 12. X = 1000 gives log10(X) = 3. The natural logarithm option uses ln(X), so X must be positive. For powers, X = 5 and Y = 3 gives 5³ = 125. For percentage, X = 15 and Y = 200 gives 15% of 200 = 30.

Inputs that are not valid in real-number mode

A square root of a negative X is not a finite real-number result in this tool, and logarithms require X greater than zero. The calculator reports an invalid-operation message instead of presenting Infinity or NaN as a useful answer. Very large powers can also exceed normal JavaScript numeric range.

Why tangent needs extra care

Tangent grows extremely large near angles such as 90° where the mathematical function is undefined. Floating-point arithmetic may show a very large finite number for an input very close to such a point. Do not interpret that as a stable physical measurement; check the mathematical domain of the function you are using.

Precision and verification

Displayed results are rounded to a practical number of decimal places. Browser calculations use standard JavaScript floating-point numbers, so tiny representation differences can appear. Keep more precision during intermediate work and independently verify safety-critical, engineering, financial or academic results when exact tolerances matter.

What this calculator is not

The interface is operation-based rather than a full expression parser: it does not accept a long formula with nested parentheses in one text box. Use the X/Y fields and operation selector for the supported functions, or use a specialist algebra system when you need symbolic manipulation, complex numbers or multi-step expressions.
