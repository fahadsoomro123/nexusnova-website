How RGB maps to a six-digit HEX color

RGB stores red, green and blue as decimal channel values from 0 through 255. Six-digit HEX represents the same three channels with two hexadecimal digits each: #RRGGBB. Decimal 0 becomes 00 and decimal 255 becomes FF, so RGB(255, 0, 0) maps to #FF0000.

Worked conversion examples

RGB(0, 128, 255) becomes #0080FF: red is 00, green 128 becomes 80 in hexadecimal, and blue 255 becomes FF. In the other direction, #FFFFFF maps to RGB(255, 255, 255), while #000000 maps to RGB(0, 0, 0).

Where these formats are used

CSS, design systems and graphics tools often accept both RGB and HEX. HEX is compact for copying into stylesheets and design tokens, while RGB can be easier to reason about when adjusting individual channels. Converting the notation does not change the intended color; it changes how the same channel values are written.

Six-digit HEX versus other CSS color forms

This tool focuses on ordinary six-digit RGB HEX values. CSS can also use shorthand forms, alpha transparency, HSL and newer color spaces. A value with transparency is not fully described by only three RGB channels, so check alpha separately when converting assets or interface colors that are not fully opaque.

Why the same value can look different on two screens

A matching numeric conversion does not guarantee identical visual appearance on every device. Display calibration, brightness, gamut, color profiles and browser color management can affect what you see. For brand-critical work, verify the final color in the actual design environment and on representative displays.

Practical checks

  • Keep RGB channels within 0–255.
  • Copy all six HEX digits for the standard form.
  • Do not assume RGB/HEX conversion includes an alpha channel.
  • Preview important colors in the final interface.
