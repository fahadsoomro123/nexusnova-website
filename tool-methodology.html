Tool Methodology & Privacy

A plain-language explanation of how NexusNova's tools produce results and where the important limits are.

Last reviewed: 23 August 2026

Browser-first design

Most NexusNova utilities run with HTML, CSS and JavaScript in the visitor's browser. Basic calculators, converters, text tools and many file workflows do not need a NexusNova application server to perform their core operation.

Image enhancement

The Photo & CCTV Image Enhancer uses deterministic Canvas processing for brightness, contrast, saturation, grayscale, sharpening and optional 2× resizing. It is not described as AI restoration because it does not infer or invent missing faces or details. A 24-megapixel output limit protects mobile devices from excessive memory use.

Image metadata cleaning

The Image Metadata Remover decodes the visible pixels and exports a fresh JPG, PNG or WebP copy. This normally drops common original EXIF, GPS and camera metadata blocks. JPG cannot contain transparency, so transparent pixels are placed on a white background for JPG output. Specialized proprietary metadata or pixel-level watermarks are outside this tool's guarantee.

Image to Text OCR

The OCR tool loads Tesseract.js only when recognition is requested. Tesseract runs in a browser worker with WebAssembly and a language model. OCR is probabilistic recognition rather than perfect transcription: small text, handwriting, blur, rotation and unusual fonts can cause mistakes, so important results should be reviewed.

QR scanning

The QR Code Scanner first tries the browser's native Barcode Detector. If QR detection is unavailable, it can load jsQR as a small fallback library. The selected image is decoded in the browser. The decoded content is displayed before any URL can be opened, because QR codes can hide phishing destinations.

SEO meta generator

The Meta Tag Generator formats entered page information into title, description, canonical, robots, Open Graph and Twitter Card markup. It provides a preview, but it cannot guarantee how Google or a social network will ultimately display the page. Search engines can rewrite titles and snippets.

Paper size and DPI

The Paper Size & DPI Converter starts from defined physical dimensions for common paper formats, converts millimeters to inches using 25.4 millimeters per inch, and multiplies inches by the selected DPI to estimate pixel dimensions. Orientation swaps width and height.

Timezone planning

The Timezone Meeting Planner interprets the entered date and time in the visitor's device timezone and formats the same moment in selected IANA timezones with the browser's Intl API. Daylight-saving changes are applied according to the browser's timezone data.

AI VRAM estimate

The AI VRAM Calculator estimates raw model-weight memory using parameter count × bits per parameter ÷ 8 and converts bytes to GiB, then adds the selected headroom. Actual inference memory also depends on architecture, KV cache, context length, batch size, framework and kernels. Training normally requires substantially more memory.

WhatsApp links

The WhatsApp Link Generator validates a 7–15 digit international number and builds the standard wa.me link with an optional URL-encoded message. NexusNova does not shorten or track the generated link and is not affiliated with WhatsApp or Meta.

Numeric calculators

Percentage, discount, bill split and related tools convert entered fields to numeric values, validate them, apply a defined formula and format the result. Invalid or impossible inputs should produce an explanatory message instead of a fabricated result.

Date calculations

Date-only calculations use calendar-safe logic because local daylight-saving transitions can make naive millisecond subtraction produce unexpected day counts.

Randomness

The password generator and random picker use the browser's cryptographic random-number source when available through Web Crypto. A generated password is not claimed to be immune to every attack; users should still avoid reuse and store credentials safely.

PDF processing

JPG-to-PDF, Merge PDF, Split PDF and related document utilities perform their core manipulation in the browser after loading the required client-side library. Users should open generated documents and verify page order and content before sharing.

How users can verify results

For important calculations, compare the result with the described formula or another trusted source. For converted files, open the downloaded output and inspect it. For OCR, review the extracted text. For professional or high-stakes decisions, use an appropriate qualified source rather than relying only on a general-purpose web tool.

Change policy

When a tool's calculation, dependency or data-handling behavior changes materially, the relevant explanation and Privacy Policy should be updated. Problems can be reported through the Contact page.
