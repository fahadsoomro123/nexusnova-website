Formula: DPI × in-game sensitivity.

What is eDPI?

eDPI means effective DPI. The basic formula is simple: mouse DPI multiplied by your in-game sensitivity. For example, 800 DPI with a sensitivity of 1.25 gives an eDPI of 1000.

Why eDPI is useful

eDPI gives you one number that combines your physical mouse setting and the sensitivity slider inside a game. It makes it easier to compare two setups in the same game, especially when one player uses 400 DPI and another uses 800 or 1600 DPI.

Do not compare eDPI blindly across different games

Different games use different sensitivity scales, so the same eDPI number can produce a different turn distance. For cross-game conversion, use a game-specific converter such as the CS2 ↔ Valorant Sensitivity Converter.

Practical setup tip

If you are testing aim settings, keep DPI fixed and change only the in-game sensitivity. Record your starting eDPI first so it is easy to return to a known baseline.

What eDPI tells you—and what it does not

eDPI combines mouse DPI and in-game sensitivity into one comparison number. For a simple scale, the calculation is DPI × in-game sensitivity. A player using 800 DPI at 0.50 sensitivity has an eDPI of 400. The same total can be reached with different DPI and sensitivity pairs.

Worked example / practical use: The number is useful when comparing settings inside the same game or sensitivity system. It does not automatically make sensitivities equivalent across different games because games can use different rotation scales, field-of-view behavior, acceleration rules and input processing.

Physical mouse feel also depends on factors eDPI does not include, such as Windows pointer settings, raw-input support, mouse acceleration, polling rate, display size and desk space. When changing settings, keep a known baseline and adjust one variable at a time so you can tell which change actually affected control.

Before you rely on the result

  • Confirm the DPI set on the mouse or its software.
  • Compare eDPI only where the game sensitivity scale is comparable.
  • Save the old settings before testing a new value.

Practical example

At 800 DPI and 0.50 in-game sensitivity, eDPI is 400. A different pair can produce the same eDPI, but that does not automatically make settings equivalent across different games with different rotation scales or input behavior.

Limits, privacy and checks

eDPI does not include field of view, acceleration, raw-input behavior, Windows pointer settings, polling rate or physical desk space. Keep your old values before changing settings and compare within a consistent game context rather than treating one number as a universal sensitivity standard.
