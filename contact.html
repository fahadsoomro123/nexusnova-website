Before sending a message

Please include a clear subject, the page or tool involved, and enough detail to reproduce any issue. Do not send passwords, recovery phrases, payment card data or other sensitive credentials.

How to report a tool problem

Include the exact page URL, what you expected to happen, what actually happened and the browser or device you were using. If the issue involves a calculator, include the non-sensitive sample inputs that reproduce the result. If it involves a file tool, describe the file type and approximate size without sending private documents unless specifically requested through a safe support process.

Clear reproduction details help separate a real tool bug from a browser permission, unsupported format, stale cached file or temporary third-party service problem. NexusNova should not label an issue fixed until the relevant page or workflow is re-tested.

Response and correction expectations

NexusNova does not promise instant support or a guaranteed response time. Reports involving broken functionality, incorrect formulas, privacy wording, misleading claims or important source-data problems should be prioritized over feature requests. Public documentation may be updated when a correction changes how a tool should be understood or used.

How NexusNova handles corrections

For tool logic or written-content issues, NexusNova aims to reproduce the problem, correct the canonical implementation and update related guidance when necessary. See the Editorial Policy and Tool Methodology for the published standards.
