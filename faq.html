HELP + FAQ

Clear answers before you use a tool.

Understand what NexusNova does, where data stays and what the current website beta actually supports.

Last reviewed: 30 August 2026

Do I need an account to use the tools?

No. Normal NexusNova browser tools remain public. Account sign-in is for the optional connected Web App experience, not a login wall for ordinary tools.

What protects sign-up and sign-in?

The live email/password flow uses Cloudflare Turnstile with server-side verification before Firebase authentication continues. The security endpoint also uses short- and longer-window request throttling to reduce automated abuse.

Why did Turnstile verify without me clicking a checkbox?

The production widget uses Cloudflare's Managed mode. Low-risk visitors can be verified without a manual checkbox, while Cloudflare can require more interaction when risk is higher.

Does creating an account start mining?

No. Account creation does not auto-start mining. The website must not invent a mining session, rate, halving stage or countdown.

Is the NVX balance on the account page real?

The account dashboard is designed to read the authenticated Firebase account state. It does not mint or change NVX in the browser. Where trusted live data is unavailable, the UI should say it is unavailable instead of fabricating a value.

Does email verification guarantee a reward?

No. Email verification is a real account-security and eligibility state, but it does not by itself guarantee an NVX reward or start mining.

How does Telegram connection work?

The supported Telegram flow uses server-verified Telegram identity data before a Telegram account is treated as linked to a NexusNova identity. Simply opening the Telegram channel or bot is not the same as a verified account link.

Are X, Facebook and Instagram shown as connected?

Only when an official supported account-linking flow is configured and verifiable. Providers that are not configured remain visibly locked; clicking a public social profile is not treated as proof of ownership.

Do social likes or follows earn NVX?

No. Following, liking, replying, reposting and viewing are voluntary community actions and are not current direct NVX reward conditions.

How do referral links work?

A valid referral can be attached after authentication when it satisfies the current server-side rules. Self-referrals are rejected, one referred account cannot freely switch between different referral owners, and signup itself does not mint a referral reward.

Are temporary email addresses blocked?

The security service can identify known temporary-email domains as a risk signal. The website does not pretend that this browser-visible signal alone has made a reward or mining decision; value-bearing enforcement must be server-side before it is claimed as complete.

Are my images and documents uploaded?

Core processing for many image, OCR, QR and PDF tools is designed to run in the browser. Some tools download client-side libraries from third-party CDNs when needed. Check the relevant tool page and Privacy Policy for details.

How accurate are calculators and converters?

Published calculators use deterministic formulas based on the entered values. For financial, legal, medical, engineering or other high-consequence decisions, independently verify important results with an appropriate authoritative source.

Is NexusNova currently a beta?

The website is undergoing a controlled beta validation phase while security, account, SEO and release-gate checks continue. Beta does not mean unfinished claims are treated as live; unsupported states remain locked or unavailable.

How do I report a problem?

Use the Contact page and include the page name, what happened and what you expected. Do not send passwords, API keys, verification codes or other secrets.
