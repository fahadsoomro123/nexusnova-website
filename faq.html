HELP + FAQ

Clear answers before you use a tool.

Understand what NexusNova Tools does, where data stays, how results are produced and what to verify before relying on an output.

Do I need an account to use the tools?

No. Most browser tools work without registration. Open the relevant tool, provide only the input required for the task and use the result.

Which newer tools are available?

The Smart Tools hub includes Image to Text OCR, QR Code Scanner, Photo & CCTV Image Enhancer, EXIF & GPS Metadata Remover, Meta Tag Generator, Paper Size & DPI Converter, WhatsApp links, timezone planning and AI VRAM estimates.

Are my images uploaded to a NexusNova server?

Core processing for the image enhancer, metadata remover and many image utilities happens in the browser. Some tools load client-side libraries from a CDN when needed, but the selected source image is not intentionally uploaded to a NexusNova processing server for those core operations.

How does Image to Text OCR work?

The OCR tool loads Tesseract.js when recognition starts and performs text recognition in the browser. OCR can make mistakes on handwriting, blur, small text or unusual fonts, so review important extracted text.

Does the QR scanner open links automatically?

No. The QR Code Scanner shows decoded content first. You decide whether to open a detected web link, which helps reduce accidental phishing redirects.

Can the photo enhancer recover missing CCTV details?

No. The Photo & CCTV Image Enhancer can adjust visible pixels, contrast and sharpening, but it cannot reconstruct information the camera never captured.

What does the metadata remover do?

The EXIF & GPS Metadata Remover creates a new browser-generated copy from visible pixels so common original metadata is not carried into the output. It is not a forensic certification tool.

How accurate are calculators and converters?

Published calculators use deterministic formulas based on the values entered. For financial, legal, medical, engineering or other high-consequence decisions, independently verify the result with an appropriate authoritative source.

Does the AI Prompt Builder call an AI model?

No. It structures text into a clearer prompt. It does not generate an AI answer or validate facts produced by another service.

Where can I learn how a tool works?

Read Tool Methodology for processing details and limitations, or browse Practical Guides and Articles.

How do I report a problem?

Use the Contact page and include the page name, what happened and what you expected. Do not send passwords, recovery phrases or other sensitive credentials.
