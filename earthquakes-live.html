How fresh is this data?

USGS says its GeoJSON summary feeds are updated every minute. NexusNova does not call USGS from every visitor's browser; it caches the feed on a scheduled publishing workflow. The USGS feed-generated time and NexusNova snapshot time above make that delay visible.

What the Pakistan-region filter means

The regional filter is a simple latitude/longitude box, 23–38°N and 60–78°E. It can include earthquakes in nearby Afghanistan, India, Iran or offshore areas, so each event's USGS place description should be used for location context.

Safety note

This page is informational and is not a substitute for official emergency alerts, local disaster-management instructions or seismological guidance. Earthquake parameters may be revised by USGS as more data are analyzed.

Recent earthquake feeds can be revised after the first report

Magnitude, depth, coordinates and event status may change as monitoring agencies receive more sensor data and review an event. The first value you see should therefore be treated as a current feed record, not an immutable final measurement.
