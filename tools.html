Why the library is smaller

A large directory of one-purpose converters can create many pages that look different in a URL but offer nearly the same depth to a reader. NexusNova is moving toward focused workbenches: fewer entry points, clearer workflows and more explanation around the result.

How to choose a tool

Choose the workspace that matches the job you are actually trying to finish. Keep original files and source values when a result matters, and use the method and limitation notes on each page to decide whether the output is suitable for your situation.

Privacy is described per workflow

“Browser-based” is not a blanket security guarantee. A page can still load a third-party library or request an external resource. Each workbench therefore describes what NexusNova does locally and where the browser or another service becomes part of the processing path.
