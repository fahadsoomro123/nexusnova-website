Scope: X-Ray evaluates visible URL-structure patterns only. It does not fetch the destination, query a reputation database, check domain age, or guarantee safety.

What X-Ray looks for

The tool checks for HTTPS, embedded credentials, raw IP hosts, punycode, shortened destinations, unusually nested subdomains, unusual ports, redirect-style query parameters and heavy URL encoding. These are caution signals, not proof of malicious intent.

Why a clean report is not a guarantee

A phishing page can use HTTPS and a normal-looking domain, while a legitimate service can use a short link or redirect parameter. X-Ray is a pre-click explanation layer. For passwords, payments or sensitive accounts, verify the destination through an official route you already trust.

Review QR destinations before opening them

A QR code can contain a website address, plain text, contact information or another encoded value. Decoding shows the payload but does not certify the destination. Inspect the domain and be cautious with unexpected login, payment or recovery-code requests.

Read the hostname carefully

Focus on the hostname before the first slash. Extra words to the left may be subdomains; the domain near the end is usually the important identity clue.
