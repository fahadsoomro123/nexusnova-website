What X-Ray looks for

The beta checks whether HTTPS is used, whether credentials are embedded in the URL, whether the host is a raw IP address, whether the hostname uses punycode, whether a link shortener hides the destination, whether an unusual port is used, and whether redirect-style query parameters contain another URL. These are caution signals, not proof of malicious intent.

Why a “clean” report is not a guarantee

A phishing page can use HTTPS and a normal-looking domain. Conversely, a legitimate service can use a short link or redirect parameter. X-Ray is a pre-click explanation layer; for passwords, payments or sensitive accounts, verify the destination through an official source you already trust.
