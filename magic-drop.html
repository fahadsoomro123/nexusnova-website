MAGIC DROP // LOCAL-FIRST BETA

Don't search for a tool. Drop the file.

Magic Drop identifies the file you selected, explains what it sees and routes you to useful actions. For images, it can also create a website-ready WebP copy entirely inside this browser tab.

SMART ACTIONS

Waiting for a file.

Magic Drop will show the file type, size and matching NexusNova tools here.

Download website-ready copy

What “website-ready” does

For supported images, Magic Drop scales the longest side down to 1600 pixels if needed and exports a WebP copy at a moderate quality setting. Re-encoding through canvas also removes common file metadata from the exported copy. This is a general web preset, not a guarantee that every website requires the same dimensions or file size.

What Magic Drop does not do yet

The first beta does not silently chain PDF operations or send files to an AI service. PDF and text selections receive matching tool suggestions. More one-click chains will only be added when the browser workflow can be verified without breaking file quality or privacy.
