Magic Drop

Drop an image, PDF or text file and get the right NexusNova tools without hunting through menus.

✓ Browser-local file inspection

Waiting for a file.

Magic Drop will show the file type, size and matching NexusNova tools here.

Download website-ready copy

What “website-ready” does

For supported images, Magic Drop scales the longest side down to 1600 pixels if needed and exports a WebP copy at a moderate quality setting. Re-encoding through canvas also removes common file metadata from the exported copy. This is a general web preset, not a guarantee that every website requires the same dimensions or file size.

What Magic Drop does not do yet

The first beta does not silently chain PDF operations or send files to an AI service. PDF and text selections receive matching tool suggestions. More one-click chains will only be added when the browser workflow can be verified without breaking file quality or privacy.

A simple file-first workflow

Select a supported file, review the detected type and size, then choose a suggested NexusNova tool for the next step. For images, the optional WebP export creates a separate copy, so keep the original until you have checked the new file visually and confirmed that its dimensions suit the destination.

Privacy and browser limits

The initial detection and supported image conversion happen in the browser. Very large files can still hit device memory limits, especially on older phones. PDF and text files are routed to matching tools rather than silently processed in a hidden chain.
