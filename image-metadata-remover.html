Why remove photo metadata?

Location privacy

Some original camera files can contain GPS coordinates or location-related EXIF fields.

Camera details

Metadata can include device model, software, timestamps and capture settings that you may not want to publish.

Local processing

This tool decodes the selected image and exports a new copy with browser Canvas APIs instead of uploading it to a processing server.

FAQ

Does this always remove GPS EXIF?

For common JPG, PNG and WebP workflows, re-encoding from visible pixels normally drops the original metadata blocks. Specialized formats and proprietary structures can require dedicated forensic tools.

What happens to transparent pixels if I choose JPG?

JPG does not support transparency, so NexusNova places transparent areas on a white background before exporting the clean JPG copy.
