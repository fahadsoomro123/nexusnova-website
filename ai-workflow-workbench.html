A prompt is an instruction contract, not a correctness guarantee

A good structure can make the requested task and output easier to inspect, but it cannot force an AI system to be factually correct. The workbench therefore treats verification as part of the workflow instead of treating a polished prompt as the finished product.

Specify what happens when information is missing

For source-grounded work, state whether the model should ask a question, mark a field as unknown, or refuse to invent a value. This makes failure behaviour explicit and easier to test.

Use output rules that can be checked

“Be concise” is subjective. “Return five bullets, include one limitation per item and use only facts from the supplied text” creates conditions a reviewer can actually inspect. Structured outputs can also be validated by software when the destination supports a schema or JSON contract.

Build a tiny test suite before trusting the workflow

Try an ordinary input, an incomplete input and at least one boundary or adversarial case. Compare the output with the requirements, verify important claims against primary sources, and run generated code in a safe environment rather than assuming the prompt made the answer reliable.

Turn a vague request into a testable contract

A useful instruction says who the model should act as, what task it must complete, what context it may rely on, which constraints matter, and what the final answer must look like. The workbench keeps those fields separate so a missing requirement is visible instead of being silently guessed.

Example

For a document-summary task, define the source text, required facts, maximum length, citation or evidence rule, and what to do when the source is incomplete. The generated checklist can then be used to review an actual model response.

Privacy boundary

This page only formats the text you enter locally. Before sending the resulting prompt to an external AI service, check that service's handling of confidential documents, credentials, personal data and retained conversations.
