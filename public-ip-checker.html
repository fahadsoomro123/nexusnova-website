Public IP vs local IP

Your public IP is the address internet services generally see for your connection. Devices on a home or office network may also have private local addresses such as 192.168.x.x or 10.x.x.x; this checker does not attempt to enumerate those local addresses.

When checking your public IP is useful

A public-IP check can help when confirming whether a VPN or different internet connection changed the address visible to websites, when comparing two network connections, or when your administrator asks which external address a connection is currently using. For example, run the checker before connecting a VPN, note the result, then run it again after the VPN is connected. A different result confirms the lookup service is seeing a different public address; it does not by itself prove that every application on the device is using the same route.

IPv4 and IPv6

The primary lookup uses an IPv4/IPv6-capable endpoint, so the result may be either format depending on your connection. A separate IPv4 lookup is attempted when available and is clearly labelled. Some networks use carrier-grade NAT or shared gateways, so several customers may appear behind one public IPv4 address. IPv6 can behave differently because devices may have globally routable addresses while still using firewall protections.

What an IP address does not tell you

A public IP is a network identifier, not reliable proof of a person's identity, exact home address or physical location. Geolocation databases can be approximate or stale, and this tool intentionally does not add those guesses. A changing address can also be normal on consumer connections because providers may assign addresses dynamically.

Privacy and security note

The tool is intentionally click-to-run. It does not start a public-IP lookup in the background, and it does not combine the result with a location database. Avoid publishing your public IP unnecessarily. If you are troubleshooting inbound access, firewall or router configuration matters in addition to the address itself.
