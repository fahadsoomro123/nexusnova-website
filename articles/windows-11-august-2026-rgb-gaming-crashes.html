Windows 11 August 2026 gaming crashes: what RGB drivers have to do with it.

Microsoft is investigating reports of certain games hanging, closing or restarting PCs after the August 11, 2026 Windows 11 security update.

What Microsoft has confirmed

Microsoft added a known issue to KB5121003 for Windows 11 versions 24H2 and 25H2. Its investigation indicates that the issue is associated with some peripherals or internal components that support RGB lighting. The affected systems can include drivers or software components with file names similar to inpoutx64.

Reported symptoms

Microsoft lists several reported outcomes: a game can become unresponsive, close without warning, show an EXCEPTION_ACCESS_VIOLATION error, or cause the PC to restart unexpectedly.

Games named in Microsoft's report

The official known-issues note specifically names ARC Raiders, MARVEL Tōkon: Fighting Souls and THE FINALS. That does not mean every player of those games is affected, and it does not prove every crash in those games has the same cause.

What should PC players do?

  1. Confirm your Windows version and update. Check whether you are on Windows 11 24H2 or 25H2 and whether KB5121003 is installed.
  2. Do not assume your GPU is failing. The current Microsoft investigation points to an interaction involving some RGB-related components on affected systems.
  3. Note your RGB software and hardware. Keyboard, motherboard, fan-controller and lighting utilities can install low-level drivers. Record what is installed before changing anything.
  4. Avoid random driver deletion. Removing low-level files manually can create a bigger problem. Microsoft has not published a universal manual fix for this issue yet.
  5. Send a Feedback Hub report. Microsoft specifically asks affected users to submit reports with Windows + F.

Is there an official fix yet?

As of August 24, 2026, Microsoft's public support page says the interaction is still under investigation and that additional details will be provided when available. Treat third-party “one-click fixes” cautiously until Microsoft or the relevant hardware/software vendor publishes a supported remedy.
