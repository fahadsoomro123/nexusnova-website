AMD Adrenalin 26.8.1: Modern Warfare 4 beta support and gaming fixes.

Editorial owner: NexusNova Editorial Team

AMD's August 20, 2026 Radeon driver adds official game support for the Modern Warfare 4 Open Beta and includes several targeted fixes.

What AMD officially added

AMD Software: Adrenalin Edition 26.8.1 lists new game support for Resonance: A Plague Tale Legacy, STAR WARS Zero Company and Call of Duty: Modern Warfare 4 Open Beta Early Access. It also adds support for the Radeon RX 9050 4GB.

Game issues AMD says it fixed

The release notes say Marvel Rivals and Subnautica 2 could fail to launch in some multi-adapter configurations on Radeon RX 7000-series and newer products. AMD also lists a fix for Modern Warfare III crashing on startup in a combined-graphics configuration on Radeon RX 9000-series products.

Should every Radeon player update immediately?

A new driver is most relevant when it adds support for a game you are about to play, fixes a problem you actually have, or supports new hardware you use. If your current setup is stable and none of the listed changes matter to you, there is usually no need to treat every driver release as an emergency.

Before updating

  1. Record your current driver version. That gives you a known baseline if performance changes.
  2. Save important game settings. Keep resolution, graphics preset, frame cap and sensitivity notes.
  3. Restart after installation. A clean restart helps ensure the new display driver is fully loaded.
  4. Test one variable at a time. If performance changes, avoid changing the driver, game settings and Windows settings all at once.
