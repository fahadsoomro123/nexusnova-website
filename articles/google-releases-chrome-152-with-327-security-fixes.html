Google Releases Chrome 152 with 327 Security Fixes

Google has promoted Chrome 152 to the stable desktop channel, rolling out hundreds of security patches across supported operating systems.

Published 2026-08-28 • NexusNova Editorial Team

Overview of the Chrome 152 Desktop Rollout

Google has started rolling out Chrome 152 to the stable channel for Windows, Mac, and Linux desktop environments. The updated release is designated as version 152.0.7977.64 for Linux, and 152.0.7977.64 or 152.0.7977.65 for Windows and Mac systems. The rollout will occur gradually over the coming days and weeks.

This release serves as a major maintenance update, delivering a total of 327 security fixes alongside general bug resolutions and performance improvements across the browser's underlying framework.

Critical and High-Severity Security Patches

The security bulletin highlights multiple critical-severity flaws, predominantly consisting of use-after-free conditions. Notable critical vulnerabilities were identified in the ANGLE graphics engine (CVE-2026-79282), the Aura windowing manager (CVE-2026-79290, CVE-2026-79052, CVE-2026-79200), Views (CVE-2026-79150), Safebrowsing (CVE-2026-79012), and Chromecast components (CVE-2026-79054, CVE-2026-79224), alongside input validation and uninitialized variable bugs.

In addition to critical issues, the update resolves a vast array of high-severity vulnerabilities across major browser sub-components. These include out-of-bounds writes and buffer overflows in ANGLE, type confusion bugs in the V8 JavaScript engine (such as CVE-2026-78938 and CVE-2026-79236), authorization flaws in the Extensions architecture, and memory safety issues across WebGL, WebRTC, and FedCM.

Google noted that bug details and direct links remain restricted to protect users until the broader user base receives the update. Access will also stay restricted if a patched vulnerability exists within a shared third-party dependency that other projects have not yet addressed.

Release Context and Testing Mechanisms

Many of the disclosed security bugs were captured prior to release using automated analysis tools and sanitizers, including AddressSanitizer, MemorySanitizer, UndefinedBehaviorSanitizer, Control Flow Integrity, libFuzzer, and AFL.

The update also credits several independent external security researchers alongside Google internal teams for reporting vulnerabilities through the Chrome vulnerability rewards process.

Practical next steps

  1. Open the Chrome menu by selecting the three vertical dots in the upper-right corner.
  2. Navigate to Help and select About Google Chrome.
  3. Allow the browser to check for updates and download version 152.0.7977.64/.65.
  4. Relaunch Chrome to complete the installation of the security patches.
