CS2 vs Valorant sensitivity: compare 360 distance instead of guessing.

Editorial owner: NexusNova Editorial Team · Updated September 20, 2026

Moving between Counter-Strike 2 and Valorant creates an easy trap: the same sensitivity number does not describe the same physical mouse movement. A useful comparison starts with the quantity that survives a game switch better: how much mouse travel produces a full 360° turn.

1. Start with a game-specific conversion

A commonly used 360-distance approximation is:

Valorant ≈ CS2 sensitivity ÷ 3.1818
CS2 ≈ Valorant sensitivity × 3.1818

Example: 1.20 in CS2 gives about 0.377 in Valorant using that approximation. Treat this as a starting point for matching physical turn distance, not as a guarantee that the two games will feel identical.

2. Why the number is only an approximation

Mouse sensitivity sits inside a larger control system. Field of view, scoped sensitivity, movement model, weapon behavior and visual feedback all affect perceived speed. Two settings can produce a similar 360 distance and still feel different during tracking or micro-corrections.

3. eDPI is useful — but mainly inside the same game

eDPI is simply:

eDPI = mouse DPI × in-game sensitivity

At 800 DPI and 1.25 sensitivity, eDPI is 1000. This is a compact way to compare setups when the game interprets sensitivity the same way. It should not be used as the sole cross-game conversion method.

4. A worked setup check

Imagine you use 800 DPI in both games and 1.20 CS2 sensitivity.

  1. Keep 800 DPI unchanged.
  2. Convert 1.20 CS2 to about 0.377 Valorant.
  3. Write both values in a short settings note so you can reproduce the test.
  4. Run the same mouse-swipe drill in each game.
  5. Measure whether the physical travel for a full turn is close to your target.

This separates a conversion mistake from a preference decision. You can then tune the setting without losing the reference point.

5. Do not change three variables at once

A common debugging mistake is to change DPI, sensitivity, crosshair and scoped multiplier together. When the new setup feels worse, there is no way to know which change caused it. Keep DPI fixed first; change one sensitivity variable; test; record the result.

6. Use a repeatable aim test

Give a new setting a short, controlled test instead of judging it from one missed shot. Use the same drill, same mouse and same DPI. Record three observations: large turns, target tracking and small corrections. A setting that feels fast during a flick may still feel unstable for fine corrections.

7. Keep a tiny sensitivity log

8. What “matching” should mean

Decide what you are matching before converting anything. “Same number,” “same eDPI,” “same 360 distance” and “same perceived feel” are different goals. A useful workflow is to match 360 distance first, then tune for the way you actually aim.
