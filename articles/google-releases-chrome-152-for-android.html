Google Releases Chrome 152 for Android

Google has begun rolling out Chrome 152 for Android, delivering stability updates and matching desktop security fixes to mobile devices.

Published 2026-08-29 • NexusNova Editorial Team

Overview of the Chrome 152 Release for Android

Google has officially launched version 152 (build 152.0.7977.64) of Chrome for Android. According to the release announcement, the update is slated to roll out gradually across Google Play over the coming days. Users can expect the new build to reach their devices as deployment expands.

The primary focus of this mobile browser release centers on overall stability and performance enhancements. These internal adjustments help maintain responsive operation and resolve technical issues that can arise during regular web navigation.

Security Parity with Desktop Platforms

A critical aspect of this update is its alignment with the desktop editions of Chrome. The development team confirmed that Android releases incorporate the same security fixes present in the corresponding desktop versions, including builds 152.0.7977.64/65 on Windows and macOS, as well as build 152.0.7977.64 on Linux.

Maintaining parity across mobile and desktop platforms ensures that vulnerabilities addressed in the core Chromium engine are mitigated on handheld devices as well. Full details regarding specific source code modifications and technical commits are documented in the project's official Git log.

Deployment Timeline and Reporting Issues

Because Google Play utilizes a staged rollout schedule, not all Android users will receive the update simultaneously. Availability will expand incrementally over several days until the new version reaches all compatible installations.

Google encourages users who encounter unexpected behaviors or glitches after updating to submit formal bug reports. This feedback allows the engineering team to address regressions and refine future minor releases.

Practical next steps

  1. Open the Google Play Store on your Android device.
  2. Navigate to your installed applications list to check if Chrome version 152.0.7977.64 is available for download.
  3. Apply the update once it appears in the store to ensure your browser has the latest security and stability fixes.
  4. Submit a bug report to the Chrome team if you experience new technical issues after updating.
