Resize before you compress when the delivery dimensions are much smaller

A camera photo can contain far more pixels than the destination needs. Reducing dimensions first can produce a large byte saving without forcing the encoder to use extremely low quality. Keep the original file as the master copy.

Format choice depends on the image

WebP is a practical web-oriented choice for many photographs and graphics. JPEG remains widely compatible for photographs but does not preserve transparency. PNG is useful when lossless pixel data or transparency matters, but it can be much larger for photographic images. The workbench shows the selected output rather than claiming one format is always best.

Fresh export and metadata

The output is rendered onto a new browser canvas before export. That means the original file is not modified and common source EXIF data is not copied into the canvas export. Do not treat this as a legal or forensic guarantee that every possible embedded application-specific chunk has been removed; verify sensitive files with a dedicated metadata inspection process when required.

Real visual quality checks

Inspect small text, faces, sharp edges and smooth gradients at the size the image will actually be displayed. A slider value alone cannot tell you whether an export is visually acceptable.

Practical example

For a 4000×3000 photo intended for a 1200-pixel-wide web slot, resizing first can remove pixels you never need to transmit. Then choose the output format and quality, compare the file size and inspect the subject at 100% before publishing.

For a transparent logo, keep PNG when transparency is required. For a photographic image where transparency is not needed, WebP or JPEG may produce a smaller result depending on the content and quality setting.

Do a delivery check, not only a file-size check

A smaller file is not automatically a better publishing file. Check dimensions, text or fine edges, transparency, and whether the destination platform recompresses the upload again. Keep the original source so another export can be made later.

Practical example

For a 4000-pixel-wide photo going into a 1200-pixel-wide website slot, set a sensible maximum width near the delivery size, export to WebP or JPEG, and compare the output file size with the original. For a transparent logo, keep PNG or choose another format that preserves the transparency your destination needs.
