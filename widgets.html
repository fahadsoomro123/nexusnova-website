Why widgets matter

A useful widget lets another website give readers a compact answer without copying data manually. NexusNova can earn referral visits while the host site gets a maintained snapshot. More widgets should only be added when the source, licensing, refresh schedule and attribution remain clear.

Embed the widget without breaking the host page

The supplied iframe uses a responsive width and a fixed starting height, so place it inside a container that has enough horizontal space on phones and desktops. Keep the title attribute for accessibility and leave lazy loading enabled when the widget appears below the first screen. If your site applies a strict Content Security Policy, allow the NexusNova frame origin before publishing.

Freshness stays with the source data

Embedding the widget does not turn reference values into a real-time market feed. The frame displays the same published NexusNova datasets and source context used by the related LIVE pages. Visitors can follow the visible NexusNova attribution when they need fuller methodology, timestamps or limitations.

When an embed is a good fit

A compact widget works best as supporting information inside a relevant article, community page or dashboard. It should not be presented as an official government, exchange or financial feed. Keep enough surrounding context on the host page to explain why the snapshot is useful, and avoid covering the attribution or source labels with overlays.
