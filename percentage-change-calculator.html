Percentage change formula

Percentage change = ((new value − starting value) ÷ starting value) × 100. A positive result is an increase and a negative result is a decrease when the starting value is positive. For example, moving from 80 to 100 is a 25% increase because the change of 20 is divided by the original 80.

How to calculate percentage change from old to new

  1. Subtract the old value from the new value.
  2. Divide that change by the old value.
  3. Multiply the result by 100 to convert it to a percentage.

For an old value of 80 and a new value of 100: (100 − 80) ÷ 80 × 100 = 25%.

Increase, decrease and percentage points are different

Percentage change always uses the starting value as the comparison base. If a rate itself changes from 20% to 25%, that is an increase of 25% relative to the old rate, but the difference is 5 percentage points. Keeping those ideas separate avoids a common reporting mistake.

If the starting value is zero, the usual percentage-change formula is undefined because division by zero is not possible. If the starting value is negative, the calculator shows a neutral signed percentage-change result because “increase” and “decrease” wording can be misleading across negative values.

Zero needs special treatment

If the old value is zero, ordinary percentage change is undefined because the formula would divide by zero. In that situation, report the absolute change or explain the before-and-after values instead of inventing a percentage. Also remember that reversing a percentage change does not usually produce the same percentage in the opposite direction because the base value changes.

Interpret the starting value correctly

Percentage change compares a new value with a starting value. The standard calculation is (new value − old value) ÷ old value × 100. A positive result indicates an increase; a negative result indicates a decrease. The starting value is the denominator, so switching the old and new values can produce a different percentage even when the absolute difference is identical.

Worked examples and everyday uses

If a subscription rises from $40 to $50, the change is $10 and the percentage increase is 25% because $10 is one quarter of the original $40. If a price falls from $80 to $60, the difference is −$20 and the change is −25%. These examples are about comparing values, not judging whether the change is fair or affordable.

Percentage change is useful when comparing month-over-month website visits, sales totals, a budget against last year's spending, or a before-and-after measurement. Keep the date range, currency, units and population consistent. Comparing a partial week against a complete week can produce a percentage that reflects different coverage rather than a genuine trend.

Important edge cases

If the old value is zero, the ordinary percentage-change formula divides by zero and is undefined. A tool should not invent a finite percentage in that situation. For values such as temperatures on Celsius or Fahrenheit scales, percentage change may also be mathematically possible but not meaningful because the scale's zero is a chosen reference point rather than an absolute absence of temperature.

Percentage change is different from percentage points. A rate moving from 20% to 25% rises by 5 percentage points, while the relative percentage increase is 25%. State which comparison you mean when reporting results.

Percentage-change questions

Why is a 50% fall followed by a 50% rise not the original value?

The second percentage is calculated from a smaller base. For example, 100 falling by 50% becomes 50; a 50% increase from 50 becomes 75.

Should rounded values be used?

Use consistent source values for the calculation, then round the displayed result to a precision appropriate to the decision.
