Percentage change formula

Percentage change = ((new value − starting value) ÷ starting value) × 100. A positive result is an increase and a negative result is a decrease. For example, moving from 80 to 100 is a 25% increase because the change of 20 is divided by the original 80.

Increase, decrease and percentage points are different

Percentage change always uses the starting value as the comparison base. If a rate itself changes from 20% to 25%, that is an increase of 25% relative to the old rate, but the difference is 5 percentage points. Keeping those ideas separate avoids a common reporting mistake.

If the starting value is zero, the usual percentage-change formula is undefined because division by zero is not possible. If both values are meaningful but the starting value can be negative, interpret the result carefully because real-world conventions differ by context.

Percentage change compares a new value with the starting value

The standard calculation is (new value − old value) ÷ old value × 100. A positive result means an increase and a negative result means a decrease. For example, moving from 80 to 100 is a 25% increase because the change of 20 is measured against the original 80.

Zero needs special treatment

If the old value is zero, ordinary percentage change is undefined because the formula would divide by zero. In that situation, report the absolute change or explain the before-and-after values instead of inventing a percentage. Also remember that reversing a percentage change does not usually produce the same percentage in the opposite direction because the base value changes.
