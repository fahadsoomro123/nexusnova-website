Privacy Policy

How the NexusNova website handles information.

Last updated: 21 August 2026

Overview

This website is designed so its current daily tools can be used without creating an account. Most calculations are performed directly in your browser.

Local browser storage

The Private Quick Note tool uses your browser's local storage so the note can remain available on that device. The website does not intentionally transmit that note to a server. Clearing site data or using a different browser/device may remove or make the note unavailable.

Server and hosting logs

The website is hosted through GitHub Pages. The hosting provider may process technical request information according to its own policies and infrastructure requirements.

Analytics and advertising

At this stage, the website does not rely on advertising code in the pages created for this initial build. If analytics or advertising services are added later, this policy will be updated to describe the relevant data use and controls before those services are treated as part of the published site.

External links

Links to external services, including GitHub, lead to third-party websites with their own privacy practices.

Changes

This policy may be updated as NexusNova adds verified features, an official domain, or new services. The date at the top will be revised when material changes are published.
