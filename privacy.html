Privacy Policy

How the current NexusNova website handles information.

Last updated: 22 August 2026

Overview

NexusNova is designed so its current browser tools can be used without creating an account. Many calculations and file operations are performed directly in the browser. The website currently uses Google Analytics 4 for traffic and engagement measurement. This policy describes the current GitHub Pages version of the site and will be updated when the custom domain, advertising or other services are materially changed.

Data entered into ordinary calculators

Values entered into percentage, date, conversion, text and similar current utilities are processed by JavaScript in the browser for the purpose of producing the displayed result. NexusNova does not currently operate a separate application server that receives those calculator inputs.

Browser local storage

The Private Quick Note tool stores its note in browser local storage. The Resume Builder can store a draft of the fields you enter, and the AI Prompt Builder can store a draft of its prompt fields. This local storage is associated with the site in that browser. It is not an encrypted password vault, may be accessible to someone using the same browser profile, and can be removed when browser/site data is cleared.

Image Compressor & Resizer

The current image tool reads the selected image in the browser, processes it using browser image/canvas capabilities and creates an output file locally. The tool does not require a NexusNova upload server for the compression/resizing operation.

JPG to PDF Converter

The current JPG-to-PDF tool reads selected JPEG files in the browser and builds the PDF locally. It does not require the selected images to be uploaded to a NexusNova application server. The generated PDF is then downloaded through the browser.

Resume and prompt content

The current Resume Builder creates a local HTML preview and relies on the browser's print/save-as-PDF function. The current AI Prompt Builder structures the text you enter but does not send it to an AI model. Users should avoid entering unnecessary secrets or sensitive information, especially on shared devices.

Developer & Web Utilities

The current JSON Formatter, Base64 encoder/decoder, URL component encoder/decoder, UUID v4 generator and SHA-256 generator perform their core transformations in browser JavaScript or the browser Web Crypto API. NexusNova does not currently send the text entered into these tools to a separate NexusNova application server. Base64 is encoding rather than encryption, and a SHA-256 digest should not be treated as secure password storage by itself.

Hosting logs and infrastructure

The website is hosted through GitHub Pages. GitHub may process technical request information and logs according to GitHub's own infrastructure and privacy practices. NexusNova does not control GitHub's server-side logging.

Google Analytics

The website uses Google Analytics 4 with measurement ID G-YLPFKWSS12 to understand website traffic and engagement. Google Analytics can process information such as page views, approximate location, device/browser characteristics, traffic source and engagement events according to Google's Analytics data practices and the visitor's browser or consent settings. NexusNova has disabled Google Signals and advertising-personalization signals in the current site configuration. Analytics is used to understand which pages and tools are useful and where the website can be improved.

Advertising and cookies

Google AdSense advertising code has not yet been added to the current published build. Google Analytics may use browser storage, cookies or similar identifiers as permitted by the visitor's browser and applicable settings. If advertising is introduced after approval, this policy and any required consent/cookie controls will be updated before the advertising setup is treated as complete.

External links

External links lead to third-party websites with their own terms and privacy practices. A link does not mean NexusNova controls the third party's data handling.

Security and sensitive data

Local browser processing reduces unnecessary file transfer for supported tools, but no general website can guarantee absolute security. Do not use the quick note as a password vault, do not place private keys or passwords into the AI prompt builder or developer utilities, and remove resume drafts from shared devices after use.

Questions and changes

This policy may change as NexusNova adds the custom domain, advertising, verified app links or new services. Material changes will update the date above. Questions can be sent through the Contact page. For technical details about current tools, see How NexusNova Tools Work or Help & FAQ.
