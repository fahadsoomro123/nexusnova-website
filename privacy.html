Privacy Policy

How NexusNova Tools and the official NexusNova account gateway handle information.

Last updated: 23 August 2026

Overview

Most NexusNova browser tools can be used without creating an account and many calculations or file operations run directly in the browser. NexusNova also provides an optional account gateway for creating or accessing the same Firebase-backed account used by the NexusNova app. The website uses Google Analytics 4 for traffic and engagement measurement.

NexusNova account registration

If you create or sign in to a NexusNova account on this website, Firebase Authentication processes the email address and password used for authentication. NexusNova website code does not store your plaintext password. During account creation, NexusNova stores an application profile in Cloud Firestore containing the account UID, display name, email address and the initial application state required by the NexusNova app. A verification email is sent through Firebase Authentication.

Referral links and attribution

A NexusNova referral link can include a referral code in the page URL. A valid-looking pending referral code may be stored temporarily in browser local storage so registration can complete without losing the invite. After authentication, the website checks the existing NexusNova referral-code record and, when eligible, creates a single pending referral relationship in Cloud Firestore. Self-referrals are not allowed. Referral verification remains subject to the NexusNova app's existing eligibility rules, including email verification and required account activity. The website does not mint referral NVX rewards client-side.

Data entered into ordinary calculators

Values entered into percentage, date, conversion, text and similar utilities are processed by JavaScript in the browser for the purpose of producing the displayed result. NexusNova does not operate a separate application server that receives those ordinary calculator inputs.

Browser local storage

The Private Quick Note tool stores its note in browser local storage. The Resume Builder and AI Prompt Builder can also store drafts locally. Pending referral attribution may use local storage as described above. Browser local storage is associated with the site in that browser, is not an encrypted password vault, may be accessible to someone using the same browser profile, and can be removed when browser/site data is cleared.

Image and document tools

The Image Compressor, Image Resizer and image-format converters read selected images in the browser and perform their core processing with browser image/canvas capabilities. The HEIC-to-JPG converter additionally loads a browser-side HEIC decoder so the selected HEIC/HEIF file can be converted locally. The JPG-to-PDF tool reads selected JPEG files in the browser and builds the PDF locally. The newer PDF merge, split and text-to-PDF utilities also perform document manipulation in the browser after loading the required client-side PDF library. These tools do not require the selected source files to be uploaded to a NexusNova application server for their core operation.

Resume, prompt and developer-tool content

The Resume Builder creates a local HTML preview and relies on the browser's print/save-as-PDF function. The AI Prompt Builder structures the text you enter but does not send it to an AI model. The JSON Formatter, Base64, URL component, UUID and SHA-256 utilities perform their core transformations in browser JavaScript or the browser Web Crypto API. Users should avoid entering unnecessary secrets or sensitive information, especially on shared devices.

Hosting and service providers

The public website is served through GitHub Pages using the nexusnovatools.com custom domain. GitHub may process technical request information and logs according to GitHub's own infrastructure and privacy practices. Firebase services are used for NexusNova account authentication, email verification, application profiles and referral attribution. Those services are provided by Google and may process technical information needed to deliver and protect the service.

Third-party utility libraries

Some optional tools load client-side JavaScript libraries from content-delivery networks only when needed. QR and PDF utilities can load libraries from cdnjs, while HEIC-to-JPG loads the MIT-licensed heic2any decoder from jsDelivr. Requesting those library files can expose ordinary web-request information such as IP address, browser information and the requested library URL to the CDN operator. The selected source image, PDF or text is processed by the tool in the browser rather than being intentionally uploaded to those CDNs.

Google Analytics

The website uses Google Analytics 4 with measurement ID G-YLPFKWSS12 to understand website traffic and engagement. Analytics can process information such as page views, approximate location, device/browser characteristics, traffic source and engagement events according to Google's Analytics data practices and the visitor's browser or consent settings. NexusNova has disabled Google Signals and advertising-personalization signals in the current site configuration. Account analytics events do not intentionally include passwords, email addresses or referral-code values.

Advertising and cookies

Google AdSense advertising code has not yet been added to the current published build. Google Analytics and Firebase may use browser storage, cookies or similar identifiers as permitted by the visitor's browser and applicable settings. If advertising is introduced after approval, this policy and any required consent controls will be updated before the advertising setup is treated as complete.

Account and data deletion

NexusNova account holders can request permanent account and associated-data deletion using the public Account Deletion page. Ownership may be verified before deletion. Limited records may be retained where reasonably necessary for security, fraud prevention, abuse prevention, dispute resolution or legal compliance.

Security and sensitive data

Local browser processing reduces unnecessary file transfer for supported tools, but no online service can guarantee absolute security. Never share your NexusNova password or verification code. Do not use the quick note as a password vault, and do not place private keys or passwords into prompt or developer utilities.

Questions and changes

This policy may change as NexusNova adds or materially changes services. Material changes will update the date above. Questions can be sent through the Contact page. For technical details about current tools, see How NexusNova Tools Work or Help & FAQ.
