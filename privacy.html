Privacy Policy

How NexusNova Tools and the optional NexusNova account gateway handle information.

Last updated: 25 August 2026

Overview

Most NexusNova browser tools can be used without creating an account. Many calculations, conversions and file operations run directly in the visitor's browser. NexusNova also provides an optional Firebase-backed account gateway used by the NexusNova app. The public website uses Google Analytics 4 for traffic and engagement measurement.

Local browser tools

Ordinary calculators, converters, timers, the WhatsApp Link Generator, Timezone Meeting Planner, AI VRAM Calculator, Meta Tag Generator and Paper Size & DPI Converter process entered values in browser JavaScript for the purpose of producing the displayed result. NexusNova does not operate a separate application server that receives those ordinary tool inputs.

Image tools

The Image Compressor, Image Resizer, format converters, Photo & CCTV Image Enhancer and Image Metadata Remover decode selected images in the browser and perform their core processing with browser image or Canvas APIs. The Metadata Remover creates a new re-encoded copy from visible pixels so common original EXIF, GPS and camera metadata blocks are not carried into the output. The source image does not need to be uploaded to a NexusNova processing server for those core operations.

OCR and QR scanning

The Image to Text OCR tool keeps the selected image in the browser and runs recognition using the Tesseract.js WebAssembly OCR engine. The OCR library and English language data are downloaded from a public content-delivery network when the visitor starts OCR. The QR Code Scanner uses the browser's native Barcode Detector when available; otherwise it can load the small jsQR library from jsDelivr as a fallback. The selected QR image is decoded in the browser and QR links are not opened automatically.

PDF tools

JPG-to-PDF, Merge PDF, Split PDF and Text-to-PDF perform their core manipulation in the browser after loading the client-side library required by the tool. Selected source files are not intentionally uploaded to a NexusNova application server for the core conversion.

Third-party client libraries

Some optional tools load JavaScript, WebAssembly or language-model files from content-delivery networks only when needed. Current examples include QR/PDF libraries, HEIC decoding, Tesseract.js OCR and the jsQR fallback scanner. Requesting those library files can expose ordinary web-request information such as IP address, browser information and the requested library URL to the CDN operator. NexusNova does not intentionally send the selected source image or document to those CDNs as an upload for processing.

Browser local storage

The Private Quick Note, Resume Builder and AI Prompt Builder can store drafts in browser local storage. A pending referral code can also be stored temporarily so registration can complete without losing an invite. Local storage is associated with the browser profile, is not an encrypted password vault and may be removed when site data is cleared.

NexusNova account registration

If you create or sign in to a NexusNova account, Firebase Authentication processes the email address and password used for authentication. NexusNova website code does not store the plaintext password. During registration, an application profile can be stored in Cloud Firestore containing the account UID, display name, email address and application state required by the NexusNova app. Verification email is handled through Firebase Authentication.

Telegram Mini App

When NexusNova is opened as the official @NexusNovaToolsBot Mini App, Telegram can provide launch data including the Telegram numeric ID, username, first and last name, language code, Premium status and profile photo URL when those fields are available. Browser-provided initDataUnsafe is used only for a temporary display preview and is not trusted as authentication or saved to local storage. The raw initData is sent to the NexusNova Firebase backend, which verifies Telegram's signature and freshness before it can be used. If the user links Telegram to a NexusNova account, a one-to-one mapping and the verified Telegram profile fields are stored in Cloud Firestore with the NexusNova profile. The Telegram bot token remains server-side and is not included in website code.

Referral attribution

A referral link can include a referral code. After authentication, the website can check the existing referral-code record and, when eligible, create a single pending referral relationship in Cloud Firestore. Self-referrals are not allowed and the website does not mint referral rewards client-side.

Google Analytics

The website uses Google Analytics 4 with measurement ID G-YLPFKWSS12 to understand page traffic and engagement. Analytics can process information such as page views, approximate location, device/browser characteristics, traffic source and engagement events according to Google's Analytics data practices and visitor settings. Google Signals and advertising-personalization signals are disabled in the current site configuration. Account analytics events do not intentionally include passwords, email addresses or referral-code values.

Advertising

Google AdSense advertising code has not yet been added to the current published build. If advertising is introduced after approval, this policy and any required consent controls will be updated before the advertising setup is treated as complete.

Account and data deletion

NexusNova account holders can request permanent account and associated-data deletion through the Account Deletion page. Ownership may be verified before deletion. Limited records may be retained where reasonably necessary for security, fraud prevention, dispute resolution or legal compliance.

Security and sensitive data

Local processing reduces unnecessary file transfer, but no online service can guarantee absolute security. Never share passwords or verification codes. Do not use the quick note as a password vault and avoid entering unnecessary secrets into developer or prompt utilities.

Questions and changes

This policy may change as NexusNova adds or materially changes services. Material changes will update the date above. Questions can be sent through the Contact page. For technical details, see Tool Methodology.
