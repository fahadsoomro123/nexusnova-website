How image compression works here

The browser decodes your image, redraws it at the dimensions you choose, then exports a new JPEG or WebP file at the selected quality. Lower dimensions and lower quality generally create a smaller file.

When to resize instead of only lowering quality

If a photo is 4000 pixels wide but you only need it for a web form or a small website card, reducing the dimensions usually saves more space than aggressively lowering quality. Keep the aspect-ratio option enabled unless you intentionally want to change the shape.

For sensitive images, local processing reduces exposure because the file does not need to be uploaded to a NexusNova server.
